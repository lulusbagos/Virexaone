# Cabin concept note

This path remains as a pointer for older project references. The active cabin application is Flutter, mirrored at the [mobile README](../../virexa_in_cabin_flutter/README.md), not a Unity mobile GUI.

Guidance uses selected-unit source GPS/heading, never phone GPS. Panah and Jejak show a straight-line destination bearing and an observed in-session breadcrumb; neither is a verified road route. The unit picker is not an operator login. Local ritase recording, slope warnings, automatic rerouting, and direct Hexagon writes from the old concept are **not implemented**.

For current boundaries use the [blueprint](../../Design/SYSTEM_BLUEPRINT.md) and [FMS readiness](../../Design/FMS_READINESS.md). The original concept remains in Git history, not as an operational specification.
